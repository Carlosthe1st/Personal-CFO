# Prestação de contas e comprovativos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Exportar relatórios completos em CSV/PDF e anexar comprovativos privados a movimentos, com autorização por organização.

**Architecture:** Reutilizar o serviço de relatórios e o histórico de movimentos. Guardar apenas metadados em PostgreSQL; binários ficam num bucket privado do Supabase e são servidos por rota autenticada. Não introduzir um segundo livro de saldos.

**Tech Stack:** Next.js 16 App Router, React 19, Drizzle/PostgreSQL, Supabase Storage REST, Vitest, `pdfkit` e `@types/pdfkit` para PDF no servidor.

**Spec:** `docs/superpowers/specs/2026-10-05-prestacao-contas-comprovativos-design.md`

## Global Constraints

- EUR e cêntimos inteiros; não arredondar saldos com `number` durante agregações.
- Cada rota valida sessão, `organizationId` e papel no servidor. Reader pode ver/descarregar; editor+ pode anexar; owner/admin pode desassociar.
- PDF/JPEG/PNG, máximo 5 MB por ficheiro e cinco anexos por movimento; bucket privado, sem URLs públicas permanentes.
- Não fazer OCR, faturação, integração bancária ou upload direto do browser para bucket com credencial privilegiada.
- Antes de editar código Next.js, ler a documentação pertinente em `node_modules/next/dist/docs/` conforme `AGENTS.md`.
- Código de produção só após teste vermelho; comentários novos, se necessários, em inglês e mínimos.

## Review Focus

1. Pedido de exportação para organização não autorizada → 403, sem bytes de dados.
2. Mais de 500 linhas no razão → exportação completa ou erro explícito, nunca CSV truncado sem aviso.
3. Ficheiro com extensão PDF mas conteúdo executável → rejeição por assinatura real.
4. Upload de duas pessoas em simultâneo até ultrapassar cinco anexos → limite imposto na transação da base.
5. Falha do bucket após validação → nenhum metadado ativo ou sucesso falso; falha da base após upload → objeto de compensação removido.

```ts
export type ExportRequest = { organizationId: string; actorId: string; from: string; to: string; accountId?: string; format: 'csv' | 'pdf' }
export async function exportReport(input: ExportRequest): Promise<{ body: Uint8Array; contentType: string; filename: string }> {
  await requireMember(input.actorId, input.organizationId, ['owner', 'admin', 'editor', 'reader'])
  assertReportPeriod(input.from, input.to, input.accountId)
  const rows = await queryExportRows(input, 50_001)
  if (rows.length > 50_000) throw new InvalidInputError()
  return input.format === 'csv' ? makeCsv(rows, input) : makePdf(rows, input)
}
const result = await exportReport({ organizationId: (await context.params).organizationId, actorId, from, to, accountId, format })
return new Response(result.body, { headers: { 'content-type': result.contentType, 'content-disposition': `attachment; filename="${result.filename}"`, 'cache-control': 'private, no-store' } })
```

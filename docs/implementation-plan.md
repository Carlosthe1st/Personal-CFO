# Plano de implementação do primeiro MVP

1. Definir tipos de domínio, dados de demonstração e regras de cálculo; testar os casos financeiros essenciais.
2. Interpretar texto em português como proposta editável; testar entradas, saídas e mensagens não reconhecidas.
3. Introduzir armazenamento local versionado, com recuperação segura de dados inválidos; testar persistência e isolamento por organização.
4. Construir dashboard, conversa, atividade e revisão com estados claros; verificar desktop e mobile.
5. Executar testes, lint, typecheck e build; documentar instalação e limitações.

O protótipo visual usa dados locais e não envia informação financeira para serviços externos.
